# Инструкция по запуску и просмотру

Пошаговое руководство для Windows. Приложение — веб-сайт в браузере; отдельный «клиент» устанавливать не нужно.

---

## 1. Что должно быть установлено

| Компонент | Минимум | Как проверить |
|-----------|---------|---------------|
| Python | 3.11 или новее | `py -3 --version` |

Если команда не найдена — установите Python с [python.org](https://www.python.org/downloads/) и отметьте **Add Python to PATH**.

---

## 2. Первый запуск (один раз)

Откройте **PowerShell** или **Терминал** в папке проекта:

```powershell
cd C:\Users\ol4ik\Projects\Kyrs
```

### Шаг 1 — зависимости

```powershell
py -3 -m pip install -r requirements.txt
```

### Шаг 2 — база данных

```powershell
py -3 -m alembic upgrade head
```

Создаётся файл `schedule.db` в корне проекта.

### Шаг 3 — демо-данные и пользователи

```powershell
py -3 -m app.scripts.seed
```

В консоли появятся логины для входа (см. раздел 4).

> Повторный `seed` не перезаписывает данные, если в базе уже есть группы.

### (Опционально) Свой администратор

```powershell
py -3 -m app.scripts.create_admin
```

Скрипт запросит email, пароль и ФИО.

---

## 3. Запуск сервера

Каждый раз, когда нужно открыть приложение:

```powershell
cd C:\Users\ol4ik\Projects\Kyrs
py -3 -m uvicorn app.main:app --reload
```

В консоли должно появиться:

```
Uvicorn running on http://127.0.0.1:8000
```

**Не закрывайте это окно** — пока оно работает, сайт доступен.

Остановка: `Ctrl+C` в том же окне.

### Альтернатива с виртуальным окружением

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
alembic upgrade head
python -m app.scripts.seed
uvicorn app.main:app --reload
```

## 4. Открытие в браузере

1. Запустите сервер (раздел 3).
2. Откройте браузер (Chrome, Edge, Firefox).
3. Перейдите по адресу:

**http://127.0.0.1:8000**

или

**http://localhost:8000**

### Учётные записи после `seed`

| Роль | Email | Пароль | Куда попадёте |
|------|-------|--------|----------------|
| Администратор | `admin@college.local` | `admin123` | Составление расписания |
| Студент | `student@college.local` | `student123` | Расписание группы **ИС-21** |

Страница входа: **http://127.0.0.1:8000/login**

Регистрация студента: **http://127.0.0.1:8000/register** (нужно выбрать группу из списка, созданного администратором).

Регистрация преподавателя: **http://127.0.0.1:8000/register/teacher** (выбор ФИО из справочника преподавателей).

## 5. Просмотр от имени администратора

Войдите как `admin@college.local`.

### Основные разделы

| Раздел | Адрес | Назначение |
|--------|-------|------------|
| Расписание (сетка) | http://127.0.0.1:8000/admin/schedule | Таблица: дни × пары; добавление занятий |
| Список занятий | http://127.0.0.1:8000/admin/entries | Все пары списком, правка и удаление |
| Группы | http://127.0.0.1:8000/admin/directories/groups | Справочник групп |
| Предметы | http://127.0.0.1:8000/admin/directories/subjects | Справочник предметов |
| Преподаватели | http://127.0.0.1:8000/admin/directories/teachers | Справочник преподавателей |
| Аудитории | http://127.0.0.1:8000/admin/directories/rooms | Справочник аудиторий |
| Периоды | http://127.0.0.1:8000/admin/periods | Семестр и **публикация** для студентов |
| Пользователи | http://127.0.0.1:8000/admin/users | Создание студентов и админов |

### Типичный сценарий для демонстрации

1. **Справочники** — при необходимости добавьте группу, предмет, преподавателя, аудиторию.
2. **Расписание** — выберите группу и период вверху страницы.
3. В пустой ячейке нажмите **«+ занятие»**, заполните форму и сохраните.
4. Попробуйте создать второе занятие в тот же слот для той же группы — система покажет **ошибку конфликта**.
5. **Периоды** — нажмите **«Опубликовать»**, чтобы студенты увидели расписание.

### Печать расписания

На странице сетки нажмите **«Печать»** или `Ctrl+P` в браузере.

## 6. Работа преподавателя

**Вход:** `teacher@college.local` / `teacher123` (после seed) или регистрация на **/register/teacher**.

| Раздел | Адрес | Возможности |
|--------|-------|-------------|
| Расписание | /teacher/schedule | Сетка по группам; правка **только своих** занятий (подсвечены) |
| Мои занятия | /teacher/entries | Список всех ваших пар |

Преподаватель может добавлять занятия, менять аудиторию, время, предмет и группу — но не может редактировать чужие пары. Конфликты (группа, аудитория, ваше двойное занятие) проверяются так же, как у администратора.

## 7. Просмотр от имени студента

**Вариант А — регистрация**

1. Откройте **http://127.0.0.1:8000/register**
2. Укажите ФИО, email, группу и пароль (не короче 6 символов)
3. После регистрации откроется расписание вашей группы

**Вариант Б — демо-аккаунт**

1. Выйдите: **Выход** в меню или http://127.0.0.1:8000/logout  
2. Войдите как `student@college.local` / `student123`  
3. Откроется **http://127.0.0.1:8000/student/schedule**

### Возможности студента

- **Неделя** — полная сетка на неделю (по умолчанию подставляется текущая чётность).
- **Сегодня** — только занятия на текущий день.
- Фильтр **Неделя** (все / каждую / нечётная / чётная) — для верхней и нижней недели.
- На узком экране (телефон) — **карточки по дням** вместо таблицы.

> Если видите сообщение «Расписание ещё не опубликовано» — администратор должен опубликовать период в **Периоды**.

### Просмотр «как на телефоне» на ПК

1. Откройте расписание студента.  
2. `F12` → режим адаптивного дизайна (иконка телефона) → выберите, например, iPhone.

## 7. Просмотр с другого устройства в локальной сети

По умолчанию сервер слушает только ваш ПК. Для доступа с телефона в той же Wi‑Fi сети:

```powershell
py -3 -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Узнайте IP компьютера: `ipconfig` → IPv4 (например `192.168.1.105`).

На телефоне откройте: **http://192.168.1.105:8000**

> Может понадобиться разрешить Python в брандмауэре Windows.

## 8. Частые проблемы

| Проблема | Решение |
|----------|---------|
| `py` не найден | Установите Python и добавьте в PATH, либо используйте `python` вместо `py -3` |
| `alembic` / `uvicorn` не найден | `py -3 -m pip install -r requirements.txt` |
| Страница не открывается | Убедитесь, что uvicorn запущен и нет ошибок в консоли |
| Пустое расписание у студента | Опубликуйте период: **Периоды → Опубликовать** |
| Неверный логин | Запустите `py -3 -m app.scripts.seed` или создайте пользователя в **Пользователи** |
| Ошибка при удалении группы | Сначала удалите связанные занятия и студентов |

### Полный сброс базы

```powershell
# Остановите сервер (Ctrl+C)
Remove-Item schedule.db -ErrorAction SilentlyContinue
py -3 -m alembic upgrade head
py -3 -m app.scripts.seed
```
