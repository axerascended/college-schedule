# Система расписания колледжа

Веб-приложение для курсовой работы по теме «Усовершенствование системы составления расписания в колледже».

## Возможности

- **Администратор:** справочники (группы, предметы, преподаватели, аудитории), составление расписания в виде сетки, проверка конфликтов (группа / преподаватель / аудитория), публикация периода для студентов.
- **Студент:** просмотр расписания своей группы (неделя / сегодня, чётная/нечётная неделя), адаптивный интерфейс.

## Стек

- Python 3.11+, FastAPI, SQLAlchemy 2, Alembic, SQLite, Jinja2, Bootstrap 5

## Алгоритм проверки конфликтов

При сохранении занятия `ScheduleConflictService` ищет записи с тем же слотом времени и пересекающимся периодом дат. Для каждой пары записей проверяется совместимость типа недели (`every` пересекается со всеми). Конфликт фиксируется, если совпадают: группа, преподаватель или аудитория.
